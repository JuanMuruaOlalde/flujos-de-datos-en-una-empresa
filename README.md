# Flujos de datos en una empresa

Este es un intento de recopilar los principales campos necesarios para procesar e intercambiar la información necesaria en la gestión de una empresa mediana/grande.

La idea es ir analizando departamento por departamento. Viendo qué datos utilizan internamente para la gestión del propio departamento y qué datos se producen en el departamento pero son más útiles a otros departamentos.

Para acabar formando un mapa señalando las fuentes de los datos y los consumidores de los mismos.

Además se va a aprovechar para reflexionar acerca de los principales obstáculos que suelen encontrarse para recoger o para transmitir esos datos. Ideando estratégias para hacer que la recogida sea menos onerosa y la transmisión más fluida.
